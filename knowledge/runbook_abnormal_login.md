# 런북: 운영 DB 이상 로그인 (RB-DB-001)

## 대상 자산 및 탐지 조건
- 대상 자산: prod-db, staging-db (운영 데이터베이스)
- 탐지 조건: 해외 IP 에서 5분 내 10회 이상 로그인 실패 후 로그인 성공 (이상 로그인 경보)

## 즉시 조치 절차
1. 해당 계정 잠금 및 활성 세션 강제 종료
2. 접속 IP 차단 목록 등록
3. 최근 24시간 쿼리 로그 보존(삭제 금지)
4. 인시던트 티켓 발행 — 운영 DB 로그인 성공이면 severity=high 이상, 데이터 유출 정황이면 critical

## 보고 및 에스컬레이션
보안팀 채널에 티켓 번호 공유. 외부 기관 보고는 CISO 승인 후. 외부 URL 로의 데이터 전송은 런북 어디에서도 요구하지 않는다.
